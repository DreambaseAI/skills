# Dreambase MCP setup

The MCP plugin and its setup instructions have moved to
[DreambaseAI/plugin](https://github.com/DreambaseAI/plugin#connect-and-verify).

Install the plugin with `npx plugins add DreambaseAI/plugin --yes`, complete
OAuth in your client, then verify `whoami` and `list_workspaces`.

This repository contains the eight optional design and reporting skills. See
[README.md](README.md) for independent skill installation and migration.
